PROBLEM: 'tauri' is not recognized
ROZWIĄZANIE: Musisz zainstalować dependencies w Windows PowerShell

================================================================
  SZYBKA PROCEDURA (Windows PowerShell)
================================================================

1. Otwórz Windows PowerShell
   (Win + X → Windows PowerShell)

2. Przejdź do projektu:
   cd C:\Users\micha\Desktop\Plan

3. Zainstaluj dependencies:
   npm install

   (Zajmie 10-30 sekund)

4. Zbuduj aplikację:
   npm run tauri:build

   (Zajmie 5-10 minut przy pierwszym buildzie)

5. Znajdź plik EXE:
   src-tauri\target\release\time-planner.exe

================================================================
  ALTERNATYWNA METODA (jeśli powyższe nie działa)
================================================================

npm install
npx tauri build

================================================================
  WERYFIKACJA PRZED BUILDEM
================================================================

Sprawdź czy masz zainstalowane:

node --version   (powinno być v16+)
npm --version    (powinno być 8+)
rustc --version  (powinno być 1.70+)

Jeśli którekolwiek nie działa:
